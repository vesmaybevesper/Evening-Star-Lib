## Release Highlight

Introducing Polyphonic! Polyphonic is a new sound focused submodule of Evening Star Lib. While its currently in early development it has been made available for those that want to start using it (it's me I'm the one who wants to start using it). 

- Renamed and relocated all utility packages
  - `ESLModChecks` -> `ModChecks`
  - `ESLPosUtils` -> `PosUtils`
  - `ESLRenderUtils` -> `RenderUtils`
  - All are now located at `dev.vesper.eveningstarlib.common.utilities`
- Added a `@Version` annotation [WIP]
  - details
- Added `getDistance`

  - Version for 2D (Vec2) and 3D (vec3) space
